## 二、论文核心方法（用户梳理 + AI 核对）

```
随机生成连续坐标的 ink dots
  → O-Net 将 x,y 编码成可微 one-hot 表示
  → 生成当前 halftone H
  → H+C 输入 P-Net
  → P-Net 预测每个 dot 的 (Δx,Δy)
  → 移动 dots 并重新生成 H
  → 对最终 H_out 计算 L_T, L_S, L_R
  → 反向传播更新 P-Net
```

### AI 补充的关键细节

| 环节 | 补充 |
|---|---|
| O-Net | ① 预先单独训练、训 P-Net 时完全冻结；② x、y 共享同一网络；③ 输入标量 (N,1)，输出 L 维向量 |
| H 合成 (Eq.2) | `H = 1 − ∏ᵢ(1 − Hᵢ)`，Hᵢ = o(xᵢ)ᵀ · o(yᵢ) 外积；I 是**全 1 矩阵**非单位阵；soft-OR 合成处理 dot 碰撞 |
| P-Net | 输出全分辨率 2 通道运动场；dot 用 `⌊xⵢ⌋,⌊yᵢ⌋` 位置**查表**取运动向量（Eq.9）；查表本身不求导，梯度走坐标+向量加法路 |
| 梯度链 | `L → H_out 像素 → O-Net 输出 → 坐标 xᵢ,yᵢ → P_out 查表值 → P-Net 参数`；O-Net 冻结只指参数不更新，梯度必须照常穿过 |
| 损失 | `L_P = L_T + 0.04·L_S + 0.08·L_R`；L_T=11×11 高斯平滑后 L2；L_S=Pang 2008 Gabor 结构度量；L_R=Xia ICCV21 预训练逆半调网络 |
| 超参 | Adam lr=1e-4；P-Net 64 通道 3×3 卷积；64×64 灰度；τ≈4 迭代；数据 UTKFace+DIV2K 4000/1000/400 |

### 训练数据（纯合成，无图像）
- 在 `[0, 63]` 步长 0.01 均匀采样，共 6400 点
- 标签 = `onehot(⌊x̃⌋)`，注意 63.99 因浮点误差 floor 到 64 → 必须 `.clamp(0, 63)`

### 损失 Eq.4
- `L_O = mean |O(x̃) − onehot(⌊x̃⌋)|₁`
- x/y 共享网络，分布相同，实现上算一遍即可

### 训练五步仪式（务必背）
1. 前向 `out = model(xs)`
2. 算损失 `loss = (out - target).abs().mean()`
3. 清空梯度 `opt.zero_grad()`
4. 反向 `loss.backward()`
5. 更新 `opt.step()`

### 验收检查点（四项全过才算完成）
1. **精度 Eq.5**：对全体采样点 `argmax(O(x̃_l)) == ⌊x̃_l⌋` 比例 = 100%
2. **二值化**：每行最大值 ≈ 1、其余 ≈ 0；热图呈阶梯状（对照论文图 7c/7d）
3. **插值**：喂未背过的小数（12.34→12, 63.99→63, 5.5→5）
4. **界外行为**：摸清 x=−0.5 / x=64.5 时的输出，为 Stage 2/5 的 clamp 做侦察

## 六、关键备忘

- 环境：macOS，Anaconda Python 3.13，初始无 torch/numpy/matplotlib
- Python 推荐 3.11（生态最稳）；macOS 下 `torch.backends.mps.is_available()` 为 True 时用 MPS
- 常见坑速查：
  - `mat1 and mat1 shapes cannot be multiplied` → 输入忘 `unsqueeze(1)`
  - loss 不降、acc≈0.016 → lr 太小，换 3e-4（0.016≈1/64 瞎猜水平）
  - acc 卡 0.98 → 正常，继续训
